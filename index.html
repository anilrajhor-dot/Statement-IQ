FINANCIAL CALCULATORS

One menu, multiple calculators

  • EMI: calculate instalment, principal, interest and repayment schedule.
  • Deposit: monthly, quarterly, half-yearly and yearly interest options.
  • Reinvestment deposit: periodic interest is added back to the deposit.
  • Age: calculate completed age and next birthday.
  • SIP: estimate maturity value, invested amount and gain.
  • Currency: choose currencies from dropdowns instead of typing currency codes.
INTEREST COMPARISON

Daily-product method

  • Calculation runs from the first to the last day of each calendar month.
  • Daily product = applicable closing balance allocated across the applicable slabs.
  • Interest is calculated as Daily Product ÷ 365 × applicable rate (%). The statement period is still split month-wise.
  • Progressive slabs apply separately to each day's balance.
  • Three slabs are built in and all limits/rates can be edited.
  • Use + Add slab when the bank has additional rate bands.

If something does not look right

Go back to Verify columns and check the detected roles. Then review flagged rows before analysing.

Interest Comparison shows no statement

Make sure at least one bank statement has been uploaded and parsed. Then reopen Interest Comparison.

A table is wider than the iPhone screen

Swipe left/right within the table. The data is not lost; the table is horizontally scrollable.

Excel figures need checking

Use the Summary, Transactions and Reconciliation sheets together and compare key totals with the original statement.
